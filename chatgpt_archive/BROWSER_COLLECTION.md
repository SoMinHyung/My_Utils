# 브라우저 수집 단계 폐지

2026-10-20 사용자 요청으로 ChatGPT 웹 화면을 열고 복사 버튼을 눌러 원문을
가져오는 단계를 삭제했다. 이 파일은 예전 예약이나 대화에서 참조할 때 삭제된
절차를 다시 실행하지 않도록 남긴 폐지 안내이며 실행 지침이 아니다.

- 백업은 [README.md](README.md)의 `collector.js` 앱 도구 조회만 수행한다.
- 이 백업을 위해 브라우저 탭을 열거나 이동·스크롤하지 않는다.
- 복사 버튼 클릭, 클립보드 읽기·쓰기, 웹 화면 이미지 다운로드, 로그인 요청을 하지 않는다.
- 누락 보완을 위한 브라우저·CUA 경로도 사용하지 않는다.
- `verification-queue`는 읽기 전용 진단 목록이며 `eligible: true`도 웹 수집 허가가 아니다.
- 예약에서 `repair-ui`를 실행하거나 삭제된 복사 도우미를 재생성하지 않는다.

과거 화면에서 확보한 원문·이미지·출처와 이전 버전은 보존한다. `repair-ui`는
이미 확보한 로컬 자료의 호환용 가져오기 기능으로만 남으며 자체 브라우저 기능은 없다.
앱 조회 도구가 제공하지 않는 질문·답변은 미확보·미검증 상태로 남긴다.
브라우저 단계 폐지는 전체 수집 완료를 의미하지 않는다.
